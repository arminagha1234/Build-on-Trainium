# NKI Lab — starter scaffold for Trainium kernel assignments

A minimal, self-contained environment + template for the NKI (Neuron Kernel
Interface) assignments. No vLLM, no XLA, no framework — just the NKI dev loop:

> **write kernel → simulate on CPU → run on Trainium → profile**

Verified on a `trn2.3xlarge` (Neuron Multi-Framework DLAMI, Neuron SDK 2.27).

## Files

| File | Purpose |
|------|---------|
| `requirements-neuron.txt` | Pinned Neuron deps (`neuronx-cc`, `nki`, `numpy`). |
| `requirements-lock.txt`   | Exact resolved versions (generated by `setup_venv.sh`). |
| `setup_venv.sh`           | Builds the pinned class venv. |
| `nki_kernels.py`          | The kernel students edit (has a worked reference). |
| `run_assignment.py`       | Harness: simulate + on-device, checks numerics, PASS/FAIL. |
| `profile_kernel.sh`       | Captures a `neuron-explorer` profile of the on-device run. |

## One-time setup

```bash
bash setup_venv.sh                 # creates ~/nki-class-venv
source ~/nki-class-venv/bin/activate
```

## The student loop

1. Implement your kernel in `nki_kernels.py` (`student_kernel`, in the `TODO` region).
2. Check correctness on CPU (fast, no device needed):
   ```bash
   python run_assignment.py
   ```
3. Run it for real on Trainium:
   ```bash
   NEURON_PLATFORM_TARGET_OVERRIDE=trn2 python run_assignment.py --device
   ```
4. Profile the on-device run:
   ```bash
   bash profile_kernel.sh
   ```

`run_assignment.py` exits non-zero if any check fails, so it can be used directly
as an autograder gate.

## Notes for instructors

- The default `student_kernel` computes `scale * a + b` so the whole pipeline is
  green out of the box. For a real assignment, blank out the compute region (or
  swap in a harder target, e.g. row-wise softmax) and adjust `reference()`.
- NKI work is simulation-heavy: students iterate on CPU (`python run_assignment.py`)
  and only need the device for the final validate/profile steps. A handful of
  shared trn2 instances comfortably serves a whole class — you do **not** need one
  instance per student.
- Bake the class AMI from `setup_venv.sh` + `requirements-lock.txt` so every
  student gets a byte-for-byte identical environment.
